# A Simple calculator using Python
  a calculator with Persian UI and bunch of useful operations that let the user choose with numbers from 1 to 6 using Python Match.
## Features
 it doesn't allow divide operations with num1 being 0\
 it detects false operations\
 letting user choose operation with numbers so the process speeds up\
 letting user decide to continue or not\
## Known Issuse/s
 entering alphabets instead of numbers for num1 and num2 will break the program
